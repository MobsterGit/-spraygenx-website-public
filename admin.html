Portfolio Upload

Select a category, add job details, choose photos from your iPhone, and prepare them for the portfolio pipeline.

First build: this page is the upload interface foundation. The final secure upload connection needs either a small serverless function or GitHub app authentication before it can push files into the repository automatically. Do not paste a permanent GitHub token into a public page.

1. Choose Category

Pick where these photos belong.

2. Project Details

Use as much or as little as you know. These details will become captions and gallery data later.

3. Choose Photos

On iPhone, tap Choose Files or Photo Library and select multiple project photos.

4. Prepare Upload

This creates the file naming plan and project metadata. The next step will connect this button to automatic GitHub upload/processing.
