# Project Image Library

Published project images live here.

Target project structure:

```text
images/projects/project-id/
  originals/
  gallery/
  thumbs/
  project.json
```

Project IDs should be lowercase and hyphenated, for example:

```text
canton-car-wash-brick-exterior
wadsworth-main-st-office
```

The upload workflow will eventually generate these folders from `upload-inbox/`.
