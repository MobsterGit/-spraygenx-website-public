# Upload Inbox

Drop new project photo folders here.

Recommended folder naming:

```text
city-job-name
```

Example:

```text
canton-car-wash-brick-exterior
wadsworth-main-st-office
```

The gallery processing script will read folders here, optimize images, create thumbnails, and publish them under `images/projects/`.

Keep original uploads organized by project. Do not mix different jobs in the same folder.
